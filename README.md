## ✨ About the Project

**Kikunuani** connects socially conscious individuals — including youth, diaspora, and local changemakers — with vetted grassroots development projects. Users can:

- Explore and support impactful community projects
- Learn about sustainable development initiatives
- Track transparency, progress, and engagement
- Access educational content and opportunities

> 💡 Our goal is to make community-driven development visible, accessible, and scalable.

## 🧪 Local Development

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/kikunuani.git
cd kikunuani

# Install dependencies
npm install

# Run the app
npx expo start
````

---

## 📦 Deployment

We use [EAS Hosting](https://docs.expo.dev/eas-hosting/quickstart/) for production builds.

```bash
# Build and deploy for web
npx eas build --platform web
npx eas deploy --profile preview
```
